# Prompt Examples

## 文章 → 7 页小红书轮播

```text
Use $crayon-doodle-illustrations 把下面文章做成 7 页小红书轮播。

要求：
- 3:4 竖版
- 暖米白纸张
- 橙红 + 钴蓝手写字
- 彩铅 / 蜡笔颗粒
- 每页一个观点
- 上半区标题与短解释，下半区一个强视觉隐喻
- 不要平台 UI，不要页码胶囊，不要左右箭头，不要底部圆点
- 不照抄参考图构图

<粘贴文章>
```

## 只做 shot list

```text
Use $crayon-doodle-illustrations 先不要生图。
把下面内容拆成 6 页图文卡，并为每页输出：
1. 核心判断
2. 主标题
3. 解释短句
4. 橙红强调句
5. 视觉隐喻
6. 构图说明

<粘贴内容>
```

## 单张观点卡

```text
Use $crayon-doodle-illustrations 为下面这句话做一张 3:4 竖版知识卡：

“工资是现金流，可携带资产才是你的。”

先把它翻译成一个具体物理隐喻，再生成图片。
不要直接画钱袋或工资条。
```

## AI / 产品主题

```text
Use $crayon-doodle-illustrations 为“Prompt 只是入口，真正拉开差距的是判断和工作流”生成一张图。

要求：
- 不要画 AI 机器人脑袋
- 用低科技、可以手绘的物理系统来解释
- 标题 2 行以内
- 正文不超过 4 行
- 底部隐喻图承担主要表达
```

## 创业主题

```text
Use $crayon-doodle-illustrations 把“能跑的 Demo 还不是能卖的产品”做成一张知识卡。
不要复用桥梁构图，至少先想 3 个隐喻，再选最清楚的那个生成。
```

## 封面

```text
Use $crayon-doodle-illustrations 为这篇文章做一张封面：

标题：为什么大多数黑客松项目不适合直接创业？

要求：
- 3:4
- 暖米白纸张
- 标题用橙红 + 蓝色手写彩铅
- 下半部一个强隐喻画面
- 不放大段正文
- 手机缩略图也能看清
```

## 统一一组已生成图片

```text
Use $crayon-doodle-illustrations 检查这 7 张图的一致性。
重点统一：背景色温、橙红与钴蓝色相、中文手写密度、人物比例、线条颗粒、插画复杂度。
只修改明显偏离整组视觉系统的页面。
```
