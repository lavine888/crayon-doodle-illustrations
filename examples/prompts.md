# Prompt Examples

下面这些 prompt 可以直接复制到 Codex 里使用。

---

## 文章 → 7 页小红书轮播

```text
Use $crayon-doodle-illustrations 把下面文章做成 7 页小红书轮播。

要求：
- 3:4 竖版
- 暖米白纸张
- 橙红 + 钴蓝中文手写字
- 明显彩铅 / 蜡笔颗粒
- 每页只讲一个核心判断
- 上半区标题与短解释，下半区一个强视觉隐喻
- 连续两页不要同构
- 不要平台 UI、页码胶囊、左右箭头、底部圆点
- 不照抄任何参考截图的具体人物、文案或构图
- 每页单独生成，不要拼九宫格

<粘贴文章>
```

## 只做 shot list

```text
Use $crayon-doodle-illustrations 先不要生图。
把下面内容拆成 6 页图文卡。

每页输出：
1. 核心判断
2. 主标题
3. 解释短句
4. 橙红强调句（可选）
5. 视觉隐喻
6. 人物动作
7. 主要物件
8. 构图说明

最后检查：
- 是否有重复隐喻
- 连续两页是否同构
- 哪页最适合作封面
- 哪页承担认知转折

<粘贴内容>
```

## 长文配图策略

```text
Use $crayon-doodle-illustrations 给这篇长文做配图策略。
不要平均切段，只选真正值得视觉化的认知锚点：
- 反常识判断
- 核心机制
- 前后对比
- 商业后果
- 边界条件
- 行动建议

默认 6-8 张。
先输出 shot list，不要生成图片。

<粘贴文章>
```

## 单张观点卡

```text
Use $crayon-doodle-illustrations 为下面这句话做一张 3:4 竖版知识卡：

“工资是现金流，可携带资产才是你的。”

先把它翻译成一个具体物理关系，再生成图片。
不要直接画钱袋、工资条、金币雨或上升曲线。
```

## AI / Agent 主题

```text
Use $crayon-doodle-illustrations 为“Prompt 只是入口，真正拉开差距的是判断和工作流”生成一张图。

要求：
- 不要画 AI 机器人脑袋
- 不要画发光大脑
- 用低科技、可以手绘的物理系统解释
- 标题 1-2 行
- 正文不超过 4 行
- 底部隐喻图承担主要表达
```

## 产品验证主题

```text
Use $crayon-doodle-illustrations 把“能跑的 Demo 还不是能卖的产品”做成一张知识卡。

先想 3 个不同物理隐喻，再选最清楚、最不俗套的那个生成。
避免漏斗、握手、火箭、靶心、拼图。
```

## 收入模型主题

```text
Use $crayon-doodle-illustrations 为“不是能收费，而是能持续收钱”生成一张 3:4 知识卡。

需要同时表达：
- 一次性收入
- 可重复收入

优先用自然或物理现象做对比，不要画标准 SaaS dashboard。
```

## 职业 / 教育主题

```text
Use $crayon-doodle-illustrations 为“学校牌子是入场券，城市产业是杠杆”生成一张图。

不要画大学排行榜。
不要画奖杯。
把“入场券”和“产业密度”翻译成同一个物理场景中的两种不同作用。
```

## 开源 / GitHub 主题

```text
Use $crayon-doodle-illustrations 为“代码仓库不等于可传播产品”生成一张知识卡。

核心差异：
代码只是原料；包装、示例、README、安装体验和可分享结果才让别人愿意继续用。

请用一个低科技工作台或加工场景表达，不要画 GitHub logo。
```

## 封面

```text
Use $crayon-doodle-illustrations 为这篇文章做一张封面：

标题：为什么大多数黑客松项目不适合直接创业？

要求：
- 3:4
- 暖米白纸张
- 标题用橙红 + 钴蓝手写彩铅
- 标题最多 3 行
- 下半部一个强隐喻主体
- 不放大段正文
- 手机缩略图也能看清
- 不要 App 轮播 UI
```

## 生成一整组 benchmark

```text
Use $crayon-doodle-illustrations 生成 8 张风格 benchmark，每张单独生成。

主题：
1. 产品验证
2. 持续收入
3. AI 交付系统
4. 城市产业密度
5. 内容复利
6. 开源产品化
7. 用户真实痛点
8. 完整产品与交付

整组要求：
- 同一暖米白纸色
- 同一橙红 / 钴蓝系统
- 同一中文手写气质
- 彩铅颗粒稳定
- 每张隐喻不同
- 不要 8 张同构模板
```

## 统一一组已生成图片

```text
Use $crayon-doodle-illustrations 检查这 7 张图的一致性。

重点统一：
- 背景色温
- 橙红与钴蓝色相
- 中文手写密度
- 标题尺寸
- 页边距
- 人物比例
- 线条颗粒
- 插画复杂度

只修改明显偏离整组视觉系统的页面，不要把不同隐喻改成同一个模板。
```

## 改图：去掉平台 UI

```text
Use $crayon-doodle-illustrations 编辑这张图。
删除所有平台轮播 UI：1/9 页码胶囊、左右翻页箭头、底部轮播圆点、App 边框和按钮。
用相同暖米白纸张自然补回。
不要动真正的插画和文字。
```

## 改图：修中文标题

```text
Use $crayon-doodle-illustrations 只修改这张图的主标题。
正确标题是：
“{正确标题}”

保持原来的手写彩铅质感、橙红 / 钴蓝配色、字号、换行和位置。
不要改变下方插画。
```

## 改图：太像 PPT

```text
Use $crayon-doodle-illustrations 这张图核心意思对，但视觉太像 PPT / 信息图。

保留核心判断，重新生成：
- 去掉规则网格
- 去掉正式方框
- 去掉 dashboard
- 去掉过多箭头
- 改成一个完整物理场景
- 保留暖米白纸和彩铅手绘质感
```

## 改图：太幼稚

```text
Use $crayon-doodle-illustrations 保持彩铅材质，但把这张图变成熟一点。
人物使用自然比例和克制表情，减少圆润 Q 版、星星爱心等装饰。
像独立杂志里的手绘知识页，不像儿童绘本。
```

## 改图：文字太多

```text
Use $crayon-doodle-illustrations 保留这张图的核心判断和隐喻，把图内文字减少约一半。
只保留：主标题、2-4 行短解释、最多 3 个物件标注。
不要通过缩小字体把原文字硬塞回去。
```
