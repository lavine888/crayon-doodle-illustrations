# Crayon Doodle Illustrations

## 核心定位

把抽象观点变成“手写讲义 + 彩铅隐喻画”的中文图文卡片。

默认不是纯插画，而是一张完整的知识卡：上半区用大号手写标题与短正文建立判断，下半区用一个具象、轻巧、略带童趣但不幼稚的视觉隐喻把概念画出来。

视觉目标：像一本认真但有趣的创意笔记——暖米白纸、明显手绘痕迹、红橙蓝三色、彩铅/蜡笔颗粒、轻微错位、不追求几何完美。

## 先读这些参考

按任务需要读取：

- `references/style-dna.md`：颜色、纸张、线条、质感、禁忌。
- `references/layout-system.md`：标题、正文、插画的版式比例与轮播一致性。
- `references/visual-metaphors.md`：如何把抽象概念变成桥、河、机器、动物、工具、容器等隐喻。
- `references/prompt-template.md`：单张生图提示词模板。
- `references/qa-checklist.md`：生成后检查与修图规则。

## 工作流

### 1. 先把正文变成“单页判断”

每一页只保留一个认知动作：

- 一个反常识判断
- 一个概念拆解
- 一个对比
- 一个因果链
- 一个方法
- 一个行动建议

不要把原文整段搬上去。先压缩成：

1. **标题**：1-3 行，最好 10-24 个中文字；
2. **解释**：2-6 行短句；
3. **强调句**：可选 1-2 行，用橙红色；
4. **视觉隐喻**：一个能“一眼看懂”的物理场景。

### 2. 默认做竖版轮播

用户未指定尺寸时，优先：

- 3:4 竖版，适合小红书/公众号插图；
- 或 4:5 竖版，适合社交平台信息卡。

一组轮播必须统一：背景、色板、标题位置、正文宽度、插画密度、留白节奏。

### 3. 先出 shot list

如果用户说“分析怎么配 / 先规划”，输出每页：

- 页序
- 核心判断
- 主标题
- 解释短句
- 橙红强调句
- 核心隐喻
- 主要物件/角色
- 建议构图

默认 5-9 页。

### 4. 明确要求生成时直接生图

如果用户明确要求“生成 / 做图 / 画出来”，不要停在建议阶段。每页单独生成，不要把九宫格拼成一张图。

提示词必须包含：

- warm ivory / cream paper background
- visible colored-pencil / crayon texture
- hand-drawn Chinese typography
- vermilion-orange + cobalt-blue + graphite palette
- imperfect wobbly linework
- editorial notebook / handmade explainer feeling
- one physical metaphor per page
- strong top-text / bottom-illustration hierarchy

### 5. 不要照抄参考截图

参考截图只用于提取**视觉语法**，不复制具体角色、构图、文案、机器、桥、鸡、直升机等元素。

每个新主题都要重新发明隐喻。可以沿用“创客手记”的世界观，但不要让输出变成对某一张参考图的复刻。

### 6. 平台 UI 不是画面元素

截图里的以下元素属于平台界面，生成时禁止画进去：

- `1/9`、`2/9` 等页码圆角胶囊
- 左右切换箭头
- 底部轮播圆点
- App 边框、按钮、导航条

## 默认视觉角色

可以使用一个“创客观察者”作为重复角色：普通年轻人/学生/创客，蓝色上衣，可有橙色帽子或橙色小配件，五官简单、比例自然、动作明确。

角色只是帮助建立系列感，不是必须出现，也不能抢过核心隐喻。不要做成固定 IP 的精确复刻。

## 输出口径

交付前简短报告：

- 一共几页
- 每页表达什么
- 哪几页最适合作封面/首图
- 如果是文件工作流，给出保存路径

不要长篇解释美术理论，让页面自己说话。
