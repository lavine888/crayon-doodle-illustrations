# QA Checklist

生成后逐页检查。

## 1. 风格

- [ ] 背景是暖米白 / 象牙色纸，不是纯白 UI，也不是脏旧复古纸。
- [ ] 有真实彩铅 / 蜡笔 / 木颜色铅笔颗粒。
- [ ] 主色控制在橙红、钴蓝、石墨灰。
- [ ] 线条有手绘抖动和压力变化，不像矢量。
- [ ] 没有 3D、玻璃拟态、霓虹、商业扁平插画感。

## 2. 文字

- [ ] 标题 1-3 行，移动端缩略图也能读。
- [ ] 正文是短句，不是把文章整段塞进去。
- [ ] 中文没有明显错字、乱码、重复字。
- [ ] 标题和正文有清楚的信息层级。
- [ ] 橙红强调不是满页乱用。

## 3. 构图

- [ ] 上文下图关系清楚。
- [ ] 一页只有一个核心观点。
- [ ] 插画不是装饰，而是在解释观点。
- [ ] 主隐喻一眼可识别。
- [ ] 留白足够，没有被小 icon 和框框填满。

## 4. 原创性

- [ ] 没有照搬参考截图中的具体构图。
- [ ] 没有机械复用上一页的桥、河、机器等物件。
- [ ] 抽象概念至少经过一次“物理化”思考。
- [ ] 避免火箭、AI 机器人、增长箭头等模板隐喻，除非语境真的需要。

## 5. 角色

- [ ] 如果有人物，比例自然，不是 Q 版大头。
- [ ] 角色动作明确，对概念有贡献。
- [ ] 角色没有变成对某个参考人物的精确复制。

## 6. 平台污染

以下内容必须没有：

- [ ] `1/9` 等页码胶囊
- [ ] 左右切换箭头
- [ ] 底部轮播圆点
- [ ] App 导航栏 / 边框
- [ ] 截图阴影和浏览器 UI

## 7. 整组一致性

- [ ] 纸张色温一致。
- [ ] 标题边距一致。
- [ ] 红蓝色相基本一致。
- [ ] 字迹密度一致。
- [ ] 人物比例一致。
- [ ] 插画复杂度没有忽高忽低。

## 失败时优先级

如果生成失败，按这个顺序修：

1. 中文错字 / 乱码
2. 平台 UI 混入
3. 画风变成矢量 / 儿童绘本
4. 信息太多
5. 隐喻太俗或太弱
6. 色板失控
7. 细节精修
