# 风格 DNA

## 一句话

暖米白纸 + 红橙蓝手写字 + 彩铅/蜡笔颗粒 + 手账式知识卡 + 一个具体视觉隐喻。

像一个懂产品、创业和 AI 的人，拿木颜色铅笔在一本旧练习册上边讲边画：聪明、松弛、有一点童真，但绝不幼稚。

## 背景与材质

- 背景不是纯白，而是低饱和暖米白 / 象牙色 / 奶油纸。
- 允许非常轻的纸张纤维与自然颗粒，但不要复古脏污、折痕、咖啡渍。
- 图像整体要有真实媒介感：彩铅叠色、蜡笔干涩边缘、铅笔排线、局部擦痕。
- 不要数字笔刷过于光滑，不要矢量描边，不要塑料感。

## 色板

### 主色

- 橙红 / 朱红：大标题、关键判断、强调、路线、主要装置。
- 钴蓝 / 群青：解释文字、次级结构、水流、框架、辅助物件。
- 石墨灰：人物头发、阴影、机械结构、次要线稿。

### 约束

- 一页最好只用红橙 + 蓝 + 灰三组色系。
- 不要彩虹色，不要霓虹，不要大面积高饱和背景色。
- 红与蓝承担信息层级，而不是装饰撒色。

## 线条

- 手绘线应有轻微抖动、粗细变化和不完美闭合。
- 轮廓可由蓝色或石墨灰勾勒，关键主体可用橙红强调。
- 机械物件可以画得细，但仍要像“手工画出来”，不能 CAD 化。
- 阴影优先用彩铅排线、稀疏交叉线，而不是数字渐变。

## 中文手写字

- 标题像粗头彩铅/蜡笔手写，笔画不完全等粗。
- 正文像蓝色签字笔 / 彩铅书写，字距自然，略有高低起伏。
- 允许关键词换橙红色。
- 不要宋体、黑体、PPT 字体感。
- 不要追求书法，也不要故意写得难认。

## 信息密度

- 一页只讲一个判断。
- 标题 1-3 行；解释 2-6 行；强调句 0-2 行。
- 插画承担至少 40% 的表达，不要靠文字解释完。
- 留白约 20%-35%，但不必像极简海报那样空。

## 人物

- 人物比例接近日常插画，不做 Q 版大头。
- 五官简单、表情明确、动作自然。
- 可以出现年轻创客、用户、投资人、客户、工程师等通用角色。
- 蓝色上衣 + 橙色帽子/配件可以作为系列性的视觉锚点，但不是强制 IP。

## 物件世界观

优先使用“可手绘的低科技物件”解释抽象概念：

- 桥、河、龙头、管道
- 自制机器、实验台、纸箱、工具
- 绳子、电线、旗子、路标
- 小动物、植物、石头、云、雨
- 手机、信封、金币、订单、盒子
- 轻量机械、螺丝、风扇、灯泡、仪表盘

这些物件可以带一点荒诞，但必须服务概念。

## 绝对不要

- 不要 PPT 信息图。
- 不要商业扁平插画。
- 不要玻璃拟态、科技 UI、赛博朋克。
- 不要 3D、黏土、皮克斯、摄影写实。
- 不要过于儿童绘本化。
- 不要把参考截图中的具体构图或角色原样复制。
- 不要平台轮播 UI：页码、左右箭头、底部圆点。
- 不要大段正文塞满页面。
