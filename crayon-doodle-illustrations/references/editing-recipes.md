# 常用改图配方

当生成结果方向对但细节不稳定时，优先局部编辑，不必每次推翻重来。

## 1. 去掉平台 UI

```text
Edit the provided illustration. Remove only the platform carousel UI elements: page counter pills such as 1/9, left/right navigation arrows, bottom pagination dots, app borders, buttons, or navigation overlays. Reconstruct the underlying warm ivory paper background naturally. Preserve all actual illustration content, handwritten text, composition, colored-pencil texture, and aspect ratio.
```

## 2. 中文标题错字

```text
Edit only the main handwritten Chinese title. Replace the incorrect text with: “{正确标题}”. Preserve the same handmade colored-pencil handwriting character: vermilion-orange / cobalt-blue, slightly uneven stroke width, dry pencil grain, natural line breaks. Do not change the illustration or layout.
```

## 3. 画面太像 PPT

```text
Regenerate while preserving the core message. Remove formal boxes, grids, polished arrows, labels, UI panels, and infographic symmetry. Convert the concept into one physical hand-drawn scene on warm ivory paper. Use imperfect colored-pencil linework and one memorable physical metaphor instead of diagram notation.
```

## 4. 太精致、太矢量

```text
Make the image materially more handmade. Increase visible colored-pencil grain, dry crayon texture, imperfect fill, wobbling outlines, slight registration mismatch, and pressure variation. Reduce smooth vector edges, perfect geometry, glossy finish, gradients, and digital polish.
```

## 5. 太幼稚

```text
Keep the crayon / colored-pencil material, but make the editorial tone more mature. Natural human proportions, restrained expressions, less rounded cuteness, fewer decorative stars/hearts, more functional objects and conceptual tension. Think independent magazine notebook, not children's picture book.
```

## 6. 文字太多

```text
Keep the core judgment and illustration. Reduce on-image text by roughly 40-60%. Keep only the main title, 2-4 short explanatory lines, and at most 3 tiny object labels. Let the physical metaphor carry the rest of the meaning.
```

## 7. 隐喻太直白

```text
Keep the exact conceptual meaning but replace the obvious stock metaphor with a fresher physical scene. Avoid generic funnels, puzzle pieces, lightbulbs, rockets, target boards, ladders, and handshake icons unless the specific context truly requires them. Use an ordinary low-tech object or situation whose physical behavior matches the idea.
```

## 8. 系列不统一

```text
Edit this page to match the existing carousel's visual system: same warm ivory paper tone, same vermilion-orange and cobalt-blue balance, same handwriting scale, same top text margin, similar colored-pencil grain, and similar illustration density. Preserve this page's unique metaphor; unify style, not composition.
```

## 9. 只保留插画，去掉文字

```text
Remove all written text from this card and reconstruct the warm ivory paper naturally. Keep every illustration object, character, line, texture, and spatial relationship unchanged. Do not add substitute labels or symbols.
```

## 10. 封面增强

```text
Regenerate this as a stronger cover card. Keep the core topic, but simplify to one dominant physical metaphor and a 1-3 line handwritten Chinese headline. Increase hierarchy and empty space. No dense body copy, no platform UI, no decorative clutter.
```

## 迭代顺序

优先级：

1. 修平台 UI 污染。
2. 修中文错字。
3. 修构图 / 信息密度。
4. 修材质。
5. 最后才修微小装饰。

不要为了修一个小错，把已经成立的隐喻和构图一起推翻。
