# 版式系统

## 默认画布

优先使用 3:4 竖版；如果平台更适合 4:5，也可使用 4:5。

## 页面层级

默认从上到下分成三层：

1. **标题区**：约 18%-28%
2. **解释区**：约 18%-25%
3. **插画区**：约 45%-58%

标题必须先抓住认知，插画负责把认知变成记忆。

## 标题区

- 1-3 行。
- 关键词可用橙红，其余用钴蓝。
- 行距紧一点，但不能挤。
- 不要居中做海报感；优先左对齐或略偏左。
- 允许一行中文 + 一行英文关键词，例如 `Hackathon = Hack + Marathon`，但英文不能喧宾夺主。

## 解释区

- 2-6 行短句。
- 每行尽量 8-18 个中文字。
- 句子之间可留半行呼吸。
- 可以用一条橙红手绘短线作为分隔。
- 允许 1-2 行橙红强调句，形成阅读节奏。

## 插画区

- 一个主隐喻场景即可。
- 主体最好占宽度 55%-80%。
- 可以有 2-4 个辅助角色/物件，但不要做成拥挤群像。
- 插画底部可以有一根橙红线/电线/河流延伸出画面，帮助轮播形成连续感。

## 轮播一致性

同一组内容中固定：

- 背景纸张色温
- 标题左右边距
- 主红、主蓝
- 正文字号感
- 插画线条粗细
- 人物比例
- 页边留白

变化应该来自每页隐喻，而不是版式乱跳。

## 封面页

封面信息更少：

- 主标题 2-4 行
- 一句副标题，可有可无
- 一个更强、更完整的主物件或场景
- 不要塞正文
- 可以让插画主体更大，占 50%-60%

## 正文页

正文页更像“边讲边画”：

- 先给判断
- 再给两三句解释
- 最后用一幅画让用户记住

## 禁止

- 不要九宫格拼贴
- 不要把每个段落做成小卡片
- 不要表格
- 不要复杂流程图
- 不要大面积框框套框框
- 不要在角落加装饰 icon 凑版面
