# Low-frequency style calibration assets

This directory mirrors the role of `assets/examples/` in a production Skill.

Use it only for occasional visual calibration when the model drifts. Do not load every image by default; text references should remain the primary instruction source.

Good calibration assets should demonstrate:

- warm ivory paper
- dry colored-pencil / crayon grain
- vermilion-orange + cobalt-blue palette
- handwritten Chinese hierarchy
- natural human proportions
- one physical metaphor per page
- large quiet negative space
- no app carousel UI

Calibration images are **not composition templates**. The model should never copy their exact objects, poses, wording, or layouts into new work.

Do not place third-party screenshots here unless you have redistribution rights. Prefer original benchmark images generated specifically for this repository.
