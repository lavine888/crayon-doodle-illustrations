# Notice

This repository provides a reusable visual-language Skill for generating original crayon / colored-pencil Chinese knowledge cards.

## Reference-image policy

The visual system is derived from general design characteristics visible in user-supplied reference screenshots: warm ivory paper, hand-drawn Chinese typography, vermilion-orange and cobalt-blue accents, colored-pencil texture, top-text / bottom-illustration hierarchy, and physical visual metaphors.

The repository does **not** include or redistribute the original reference screenshots. The Skill explicitly instructs the model not to copy distinctive characters, exact compositions, wording, machines, animals, props, or platform UI from those references.

Use the references as visual grammar, not as templates.

## Generated outputs

Users are responsible for reviewing generated images, text accuracy, third-party marks, and usage rights before publication.
